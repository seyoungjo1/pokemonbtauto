# 포켓몬 챔피언스 배틀 AI

포켓몬 챔피언스 싱글(6→3)·더블(6→4)에서 **파티 짜기 → 선출 → 배틀**을 돕고,
그 전체를 자기대전으로 계속 학습하는 프로그램입니다 (알파고 제로식 반복).

## 실행

| 파일 | 하는 일 |
|---|---|
| `run.bat` | 앱 실행. 처음엔 가상환경을 만들고, 매번 업데이트(프로그램·데이터·모델)를 확인한 뒤 브라우저가 열립니다 (http://127.0.0.1:8730) |
| `밤샘학습.bat` | 밤샘 학습. Node.js 확인 → 쇼다운 최신판 빌드 → GPU용 PyTorch 설치(처음 1회) → 셀프테스트 → 시간·형식을 묻고 학습. 멈추려면 폴더에 `학습중지.txt` 를 만듭니다 |

필요한 것: Python 3.10+, (시뮬레이션·학습용) [Node.js LTS](https://nodejs.org), (GPU 학습용) NVIDIA 드라이버.

## 화면

| 탭 | 내용 |
|---|---|
| 파티 짜기 | 내 보관함에서 6마리 + 특성·도구·성격·SP·기술까지, 메타 파티들과 **선출→배틀** 대전으로 평가하며 다듬기 · 1마리 추천 |
| 팀 | 팀 편집(쇼다운/한글 텍스트 가져오기·내보내기), AI 육성 추천(SP·성격·기술·도구) |
| 선출 | 상대 6마리 입력 → 빠른 추천(상성) / **대전 시뮬레이션 선출**(선출 승률표 + 균형해: 메타 상대 최선 · 가장 안전한 선출) |
| 대전 | 보이는 대로 HP·상태이상·랭크·필드·상대가 쓴 기술 입력 → 행동 추천(신경망 추천 확률, 수읽기를 켜면 행동별 예상 승률), 데미지·위협표, 행동 순서, 상대 세트 추정, 관측 데미지로 상대 세트 좁히기 |
| AI와 대전 | 내 팀(또는 메타 팀)으로 AI 와 실제 대전 — 상대 수준: 수읽기·신경망·선생님·최대 데미지·쇼다운 기본 AI. 끝난 대전은 사람 기보로 학습 데이터에 더해짐 |
| 계산기 | 16단계 난수까지 데미지 계산 |
| AI·학습 | 신경망 상태, 상대별 승률, 셀프테스트, 변수 장부, 학습 기록, 내 대전 분석 |
| 설정 | 업데이트, 규칙(데이터) 선택, 포켓몬 그림 받기, 화면 테마 |

## 구성

- **데이터** `data/<규칙>/`: 쇼다운 챔피언스 모드에서 추출 + PokeAPI 한글 이름 + 메타 통계(배틀스타디움 싱글·VGC 사용률, 스모곤 세트). GitHub Actions 가 매일 갱신합니다 (`update-data.yml`) — 최신 쇼다운과 데미지 대조 셀프테스트를 통과할 때만.
- **데미지 엔진** `engine/damage.py`: 쇼다운 시뮬레이터와 16단계 난수·급소까지 대조해 무작위 4,907건 100% 일치.
- **상대 세트 추정** `engine/belief.py`: 메타 통계 + 드러난 기술·도구·특성 + 관측 데미지.
- **수읽기** `engine/search.py` + `tools/ps_search.js`: 상대 세트를 여러 번 뽑아 쇼다운 엔진으로 몇 턴 앞을 굴림, 판세는 남은 포켓몬끼리의 대결 예측으로 평가.
- **신경망** `engine/nets.py` (+ `nets_torch.py` GPU): 결정마다 모든 선택지에 대한 정책 + 승률 가치 (알파고 제로식 손실).
- **선출** `engine/bring.py`: 선출 승률표를 끝까지 대전으로 채우고 행렬 게임으로 풂.
- **파티 최적화** `engine/teamopt.py`: 6마리 × 모든 세트 요소를 대전으로 평가하며 개선, 평가 기록은 학습 데이터.
- **밤샘 학습** `tools/overnight.py`: 쇼다운 리플레이 받기 → 수읽기 리그 대전 생성(여러 코어) → 지금 최고 신경망에서 이어서 GPU 학습(사람 기보 30% 섞기) → 기본 AI·이전 신경망과 대결해 이길 때만 교체 → 파티 최적화 → `reports/insights.md`.
- **쇼다운 기보 학습** `tools/fetch_replays.py` + `engine/replay_parse.py`: 리플레이(관전자 로그)에서 양쪽 플레이어 시점과 선택지를 다시 만들어 사람의 선택을 따라 배움. 해석 정확도는 정답을 아는 우리 대전으로 셀프테스트(싱글 100%·더블 96%).
- **패치·새 기믹 적응** `tools/patch_diff.py` + `engine/nets.py surgery()`: 바뀐 포켓몬·기술 감지 → 그 포켓몬 위주로 대전, 새 변수는 신경망 수술(출력 보존)로 붙여 처음부터 다시 하지 않고 이어서 학습. 조사·실험: [`docs/STUDY.md`](docs/STUDY.md).

## 지금까지 측정한 실력 (싱글, 40판씩)

| 우리 AI | 쇼다운 기본 AI | 최대 데미지 AI | 선생님 AI |
|---|---|---|---|
| 선생님 AI (데미지 계산 규칙) | 80% | 60% | – |
| 신경망 정책 (600판 모방학습) | 85% | 55% | 50% |
| 수읽기 AI | **92%** | **62%** | **72%** |

기록: `reports/arena.md`, 학습 리포트: `reports/insights.md`, 변수 장부: `FEATURES.md`.

## 셀프테스트

`python tests/selftest.py` — 데이터 · 능력치 · 데미지(쇼다운 대조) · 팀 텍스트 · 변수 · 시뮬레이터(승자 집계·수읽기·선출표) · 리플레이 해석(정확도·별명·메가 규칙) · 신경망(+수술 출력 보존) · PyTorch(GPU) 경로.

## 토큰 배틀망 학습 (PC · 1단계 — 재설계안 `docs/ARCHITECTURE.md`)

포켓몬을 이름이 아니라 **종/능력치·특성·도구·기술×4 요소 토큰**으로 쪼개 어텐션으로 묶는 새 신경망입니다. 학습·평가는 모두 JSON 을 돌려주므로 나중에 MCP 도구로 그대로 쓸 수 있습니다.

```
python tools/train2.py status                       # 모델·데이터·토치(CUDA) 현황
python tools/train2.py bc   --type singles          # 기보(30%) + 자기대전으로 정책·가치 학습 → models/battle_singles_candidate.json
python tools/train2.py eval --type singles          # 후보 vs 선생님 AI · 지금 토큰망 — SPRT 순차검정 (최대 400판)
python tools/train2.py adopt                        # 게이트를 통과한 후보를 채택
python tools/train2.py all                          # 위 셋을 차례로
python tools/feasibility.py prep && python tools/feasibility.py run   # 요소 토큰 인코더 가능성 시험 (존재 쌍 경주값, 데이터 없는 종 일반화)
python tools/bench.py --me tokennet --vs heuristic --games 100       # 아키타입 벤치마크 거울전 (신뢰구간)
```

GPU(CUDA) 가 있으면 `engine/battlenet_torch.py` 로 학습하고, 없으면 numpy(`engine/battlenet.py`)로 같은 구조를 학습합니다 (`--tiny` 는 작은 시험용).

## 기보 받기 (직접)

```
python tools/fetch_replays.py all --type singles     # 받기 → 해석 → 기보로 학습·평가
python tools/patch_diff.py                           # 지난 학습 이후 바뀐 데이터 보기
```
