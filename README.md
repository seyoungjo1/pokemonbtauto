# 포켓몬 챔피언스 배틀 AI (개발 중)

포켓몬 챔피언스의 싱글(6→3)·더블(6→4) 대전에서 매 턴 최선의 수를 추천하고, 자기대전으로 계속 학습하는 프로그램입니다.

## 지금 되는 것
- **챔피언스 데이터**: 쇼다운 챔피언스 모드에서 추출 + PokeAPI 한글 이름 (`data/champions/`)
- **메타 통계**: 배틀스타디움 싱글·VGC 2026 사용률, 스모곤 전문가 세트 (`tools/fetch_meta.py`, 날짜·버전 기록, 바뀌면 이전 것은 `history/`)
- **데미지 엔진**: 쇼다운 시뮬레이터와 16단계 난수·급소까지 대조 — 4,907개 무작위 사례 100% 일치 (`python tests/selftest.py`)
- **자기대전**: 쇼다운 시뮬레이터로 6→3 / 6→4 대전, 플레이어 시점 정보만 기록 (`tools/train.py selfplay`)
- **상대 세트 추정**: 메타 통계 + 드러난 기술·도구 + 관측 데미지로 좁히기
- **수읽기(탐색)**: 상대 세트를 여러 번 뽑아 쇼다운 엔진으로 몇 턴 앞을 굴림 (`engine/search.py`, `tools/ps_search.js`)
- **화면**: 팀 편집·선출 추천·대전 입력·추천·계산기·AI 학습 현황 (`python app.py` → http://127.0.0.1:8730)
